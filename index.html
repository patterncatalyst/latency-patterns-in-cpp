What this guide is

A chapter-based, hands-on path through latency engineering in C++23. Every chapter measures one pattern against the same running example: a parcel sortation line moving a parcel through checkweigh, dimension, scan, label, and sort. The metric that matters is scan-to-divert, the time from sensing a parcel to acting on it, because the belt never waits for a slow consumer. Three chapters add a Rust lane side by side in the tabbed code component, where ownership and the type system change what a technique has to prove. One chapter runs in a throwaway virtual machine; the rest run unprivileged, on the host, as they are.
